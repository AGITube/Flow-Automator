Releases

What's new, improved, and fixed in AGITube Flow Automator.

New to reference images and naming? See the Prompt Guide for copy-ready examples of @tag and #name.

Version 1.6.0

Latest

New

  • Works with the new Google Flow — Google rebuilt the Flow website, which had broken generation. The extension now runs on the updated flow.google.com, with image and video generation restored — including upscales and reference uploads.
  • Multiple reference images in one prompt — use several @tags in a single prompt (e.g. @alex shaking hands with @sam) and each reference is placed in the right spot, so multi-character and multi-product scenes come out correct.
  • Keeps generating in background windows — start a batch, switch to another window or Chrome profile, and it keeps running at full speed instead of pausing. Great for running several projects side by side.
  • In-app announcements — important updates now appear as a banner inside the extension, so you'll know right away if something needs your attention.
  • Version shown in the header — the current version is displayed next to the title.

Improved & fixed

  • Instant Stop — pressing Stop now halts the batch immediately instead of taking several seconds.
  • Cleaner daily-limit handling — when a model hits its daily limit, the batch stops cleanly and keeps everything already done. Switch to another model and press Start → Resume to continue from where it stopped.
  • Clear guidance on "unusual activity" — if Google flags your session after heavy use, the extension now shows a step-by-step guide to clear it and resume, instead of silently stalling.
  • Blocked prompts are skipped, not retried — a prompt rejected by Google's content policy now shows a clear message and is skipped, so it no longer holds up the batch.

Version 1.3.0

New

  • Generation Speed — run your batch in parallel — a new Speed control sits right above your prompts (in both Image and Video). Instead of finishing one job before starting the next, it can send several at once. Choose Fast (the new default), Balanced, Slow (one at a time), or Custom to set your own delay between jobs — so a big batch finishes far quicker.
  • Dependencies are handled automatically — a prompt that references an @name created earlier in the same batch waits for that image to finish first, then runs. Everything independent keeps generating in parallel, so chained characters and products stay correct even at full speed.

Improved & fixed

  • Auto-paces under load — if Google starts throttling during a fast run, the queue automatically slows to one at a time and speeds back up once things recover.
  • Cleaner watermark removal — the corner logo is now cleared more reliably, including on flat illustration styles and dark backgrounds where a faint outline of the sparkle could remain. Your images stay untouched everywhere else.
  • Session stays fresh during parallel runs — Refresh Flow tab every N now works in Fast/Balanced mode too: it waits for the in-flight jobs to finish, refreshes once, then continues — so a long batch keeps a healthy session without interrupting any running job.

Version 0.4.8

New

  • Download a whole run as a ZIP — open Queue History and click the new download icon on any past run to grab all its images (or videos) in one click — watermarks removed, folder / subqueue layout preserved, saved with a clean name.
  • Auto-retry failed prompts — a prompt that comes back empty now retries automatically (up to 3×), so there are fewer gaps in your batch. Manual retry still works too.
  • Bigger batches — up to 500 prompts — the load-prompts limit jumped from 150 to 500.

Improved & fixed

  • Bigger per-prompt & @tag references — per-prompt references and @name tags in a single prompt are raised to 100 too, so you're no longer capped when a prompt needs many references.

Improved & fixed

Version 0.3.0

New

  • Video generation is here — batch-generate videos on Google Flow the same way you batch images. Choose Text, Start frame, Start + End frame, or Reference mode, set your model, aspect ratio, duration and videos-per-prompt, and let it run.
  • Separate Image & Video tabs — switch between Image and Video at the top of the panel. Each keeps its own prompts, queue, and history, so setting up one never disturbs the other.
  • Per-clip frame tags — name the exact frames a single video should use, right in its prompt: @start:name, @end:name, and @name for references. Multi-word names use brackets, e.g. @start:[my hero].
  • Different frames for each prompt — assign a start / end / reference image to every prompt from a grid, no tags needed. A tag in the prompt wins, then a per-prompt assignment, then the shared frames in Settings.
  • Per-prompt image references — in the Image tab you can now add up to 4 reference images to a single prompt, over and above your global Subject / Scene / Style set.
  • Reference Library with your generated images — pick references from your Flow Library, including images you generated in this run, and upload new ones from the same place.
  • Organized downloads — videos save into their own run folder, kept separate from your images.

Improved & fixed

  • Free daily limit counts every generation — video generations now draw from the same daily allowance as images.
  • Retry does the right thing per mode — retrying a video job regenerates a video (not an image), and each mode keeps its own queue and history.
  • Cleaner navigation — settings moved into a dialog, and image/video controls now share one consistent layout and wording.

  • Download folders — running alongside our Vibes extension no longer sends files to the wrong folder.

Version 0.2.0

New

  • Reference an image by name — write @name in a prompt to pull that image in as a reference. Works with images named in Flow, uploaded this session, or made earlier in the same batch. Multi-word names use @[name with spaces].
  • Name your results with #name — add #name to a prompt to name the image it creates, then reuse it later with @name. Perfect for keeping the same character or product consistent across a whole batch.
  • Retry any job — regenerate a finished, failed, or stopped job as a new version (v2, v3…) with one click — even while the queue is still running (it jumps ahead and runs next).
  • Subqueues — when you retry a job whose result other jobs reference, start a subqueue to re-run that whole dependent chain in its own tab and subqueue_N folder, so every image stays in sync with the updated reference. Run several at once; all queues process round-robin.
  • Rerun, resume & regenerate — press Start on a finished batch to regenerate every image again as new versions in the same batch; on a stopped batch, choose to resume the remaining jobs (keeping what's already done) or start the whole batch over. Resumed jobs pick up any references you retried in the meantime.
  • Reference previews in the queue — every job shows a thumbnail of each @tag it uses before you start. A reference that a later prompt creates shows a "step N" chip that fills in with the real image once that step runs.
  • Click to preview — click any thumbnail (a generated result or a reference chip) to view it full-size instantly, no waiting for a refresh.
  • Edit a prompt — a ✎ button opens an editor to fix a wrong @name or a typo from a bulk load — before you start a run, or on a finished job right before retrying it.
  • Product tour — a quick first-run walkthrough of the whole panel, replayable anytime from Account.
  • New model: Nano Banana Lite — added alongside Nano Banana 2 and Nano Banana Pro.
  • More reference slots — Scene and Style now hold up to 5 images each (10 total across Subject + Scene + Style combined).
  • Fresh session between runs — the Flow tab refreshes automatically when a run ends or is stopped, so the next batch starts clean.
  • In-app Prompt Guide & support — a Prompt Guide button next to your prompts, plus a direct link to our Discord community for help.

Improved & fixed

  • Expired sign-in no longer shows a broken "Trial — / —" state — it takes you straight back to sign in.
  • "Unusual activity" recovery — a blocked generation is now auto-retried with a fresh security check, and a built-in guide walks you through clearing Google's block if it persists.
  • Clearer errors — daily-limit, rate-limit, and expired-session cases now show distinct, actionable messages.
  • Smoother queue — reference thumbnails no longer flicker when you press Start.
  • Trashed references — images you move to trash in Flow are no longer offered or used as @name references.
  • Retry downloads — retrying a job on a finished or stopped queue now saves into the batch folder instead of the Downloads root.
